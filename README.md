# Teen AI YT

Welcome to the open-source repository for the **@AICourseforKidsandTeens** YouTube channel!

## Overview
This project, co-hosted by Maysam and Jordan, aims to build an automated live streaming and video editing application. Our goal is to leverage AI to create engaging content and teach kids and teens about artificial intelligence.

## Features (Planned)
- Automated Live Streaming
- AI-Powered Video Editing
- YouTube Channel Integration

Stay tuned as we build this project from the ground up!
